# LO7 applied case - SharePoint agent answer

## Scenario

The private `IES GenAI for Engineers` SharePoint site contains four synthetic sources in `Documents/Engineering Knowledge Base`. The `IES Engineering Knowledge Assistant` returns a cited comparison of the FMEA, DMAIC and SPC workbooks. A second query correctly says that TR-401 does not state a delivery target or comparison range.

## Learner task

Apply all seven security steps before deciding whether the output may be shared as a classroom example.

1. Classify the source data as synthetic training data and state the permitted use.
2. Confirm the site is private, the folder is the selected source and the intended audience has access.
3. Inspect the prompt for credentials, unnecessary personal data, overbroad scope and prompt-injection risk.
4. Open one citation; reproduce one workbook calculation; confirm units and the stated limitation.
5. Record an authorised engineer's approve, reject or return decision.
6. Log the source revision, prompt, output, correction, reviewer and time.
7. If unexpected restricted information, a suspicious instruction or access mismatch appears, stop sharing, preserve evidence and use the organisation's incident route.

## Expected decision

The output may be retained as a **draft synthetic classroom example** after citation and calculation checks. It is not an operating instruction, safety decision or engineering approval. If access, evidence or human sign-off is missing, return it for correction or do not share it.
