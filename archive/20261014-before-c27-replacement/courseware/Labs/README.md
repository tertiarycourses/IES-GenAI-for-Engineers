# IES GenAI for Engineers — Hands-On Labs

Seventeen short, connected activities that sit inside the six module time boxes of the approved
Lesson Plan. Every folder holds `Lab-Instructions.pdf` with each step and Copilot prompt, a
formatted `Starter.xlsx`, and the mock data for that activity.

Module 2 follows one roadside drainage inspection through four Copilot apps — Excel, Word,
Outlook and PowerPoint — carrying a single `Work-Order-Register.xlsx` from lab to lab. Modules 3
to 6 use the CW-401 chemical dosing skid.

## Module 3 — the three engineering methods, in teaching order

The methods are taught and practised in this order, because that is the order they answer questions in:

| | Method | Question it answers | Lab |
|---|---|---|---|
| 1 | **FMEA** | What could fail? | [Lab 3.1](Lab-3.1-FMEA-Document/Lab-Instructions.pdf) |
| 2 | **DMAIC** | How will we improve? | [Lab 3.2](Lab-3.2-DMAIC-Report/Lab-Instructions.pdf) |
| 3 | **SPC** | Is the process stable? | [Lab 3.3](Lab-3.3-SPC-Control-Chart/Lab-Instructions.pdf) |

Each of the three uses Copilot in Excel to analyse the data, build the chart and draft the output.
