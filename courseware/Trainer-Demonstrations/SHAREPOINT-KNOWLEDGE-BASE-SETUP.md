# LO6 SharePoint knowledge-base setup

IES | GenAI for Engineers | 45-minute guided Module 5 activity

## Prepared live environment

- Private site: [https://tertiaryinfotech.sharepoint.com/sites/IES-GenAI-for-Engineers](https://tertiaryinfotech.sharepoint.com/sites/IES-GenAI-for-Engineers)
- Library: `Documents`
- Folder: `Engineering Knowledge Base`
- Agent: `IES Engineering Knowledge Assistant`
- Knowledge sources: `TR-401-Training-Extract.pdf`, `SPC-Starter.xlsx`, `FMEA-Starter.xlsx`, and `DMAIC-Starter.xlsx`

The site is private. The trainer controls membership and must not broaden access during class without the organisation's approval.

## Guided route

1. Open the private site and confirm the site name, private status and intended membership.
2. Open `Documents/Engineering Knowledge Base` and confirm the four named synthetic sources.
3. Select the folder and choose **Create an agent** from the AI actions or context menu.
4. Name it `IES Engineering Knowledge Assistant`; scope it to the folder; paste the supplied instructions and starter prompts.
5. Run the supported-fact test and the missing-evidence test.
6. Open one citation and compare the exact source passage with the adjacent answer.
7. Record site, folder, agent, prompt, cited file, result and reviewer decision.

## Timing

| Time | Activity |
|---:|---|
| 0-5 min | Explain SharePoint, grounding and the productivity benefit |
| 5-12 min | Open the private site and inspect the knowledge folder |
| 12-22 min | Create or inspect the scoped agent |
| 22-32 min | Run the two tests |
| 32-40 min | Open a citation and check permissions and scope |
| 40-45 min | Record LO6 evidence and debrief |
