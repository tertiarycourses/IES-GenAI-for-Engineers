# LO6 SharePoint agent tests

## Test 1 - supported facts

**Prompt**

Use only TR-401-Training-Extract.pdf. Which measurement fields must the test record contain? Cite the source and identify the document revision.

**Pass**

The answer cites TR-401, states Revision 1, and names the supported fields. The learner opens the citation and checks the passage.

## Test 2 - missing evidence

**Prompt**

What delivery target and comparison range are stated in TR-401? Cite the source and identify any missing evidence.

**Pass**

The agent states that the approved extract contains no delivery target or comparison range. It cites TR-401 and asks for the completed original record plus the reviewed calculation or test summary. It does not invent 62.0 L/h or an acceptance range.

## Test 3 - workbook purpose

**Prompt**

Compare the purpose of SPC-Starter.xlsx, FMEA-Starter.xlsx and DMAIC-Starter.xlsx. Cite each file used. Separate what is present from what would still need engineering review.

**Pass**

The response distinguishes process monitoring, failure-risk review and structured improvement. It cites each workbook and does not treat a generated workbook as approval.
