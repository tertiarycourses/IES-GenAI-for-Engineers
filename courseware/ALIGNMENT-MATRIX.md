# IES GenAI for Engineers — alignment matrix

The six-module Lesson Plan controls the one-day delivery. The PPT, guides and lab folders use the same route and outputs.

| Teaching block | PPT slides | Lesson Plan | Learner / Facilitator Guide | Lab folder | Learner output |
|---|---:|---|---|---|---|
| Module 1 | 3–10 | Module 1 · overview | Copilot and engineering task | — | A clear request ready for analysis |
| Module 2 | 11–21 | Module 2 · overview | Prompt framework and persona challenge | — | A constrained, reviewable prompt |
| SPC | 25–30 | Module 3 · 25 min | SPC explanation and guided check | `Labs/Lab-01-SPC` | Three-sentence chart interpretation |
| FMEA | 31–35 | Module 3 · 20 min | FMEA explanation and guided check | `Labs/Lab-02-FMEA` | One evidence gap and one proposed action |
| DMAIC | 36–41 | Module 3 · 20 min | DMAIC explanation and guided check | `Labs/Lab-03-DMAIC` | Measured change, limitation and next evidence |
| Agents | 42–49 | Module 4 · demonstration | Prepared FMEA/report assistant | `Trainer-Demonstrations` | No independent deployment task |
| Grounding | 50–55 | Module 5 · demonstration | Approved-library retrieval walkthrough | `Trainer-Demonstrations` | Citation, revision and scope check |
| Security and close | 56–63 | Module 6 · review | Seven checks, summary and reusable prompt | `Labs` prompt banks | One prompt and one review rule |

The three Excel exercises total **65 minutes** (25 + 20 + 20) and use one prepared `Worked-Reference.xlsx`. The remaining reference examples are optional after-class material and do not add classroom time.
