# FMEA Output Template

Fictional training reference. Reproduce these columns in this order for every failure mode.

| Field | Rule |
|---|---|
| Item / Function | The function that is lost, not the part name alone. |
| Failure Mode | How the function fails, in observable terms. |
| Effect | Consequence on process, people or environment. |
| Cause | The mechanism. Say UNKNOWN when the source does not state it. |
| Current Control | The control that exists today. Planned controls do not belong here. |
| S / O / D | Each with a one-line rationale citing the source. |
| RPN | S x O x D, formula shown. |
| Severity Flag | Mark ESCALATE when S is 9 or higher. |
| Proposed Action | One practical next step. Never an approval. |
| Evidence Request | The specific record needed to confirm a rating. |
| Owner | As stated in the source, otherwise NOT STATED. |
| Due Date | As stated in the source, otherwise NOT STATED. |
| Source | Document ID and revision. |
| Review Status | Always DRAFT FOR REVIEW. |

Close every output with the unresolved questions and the words DRAFT FOR REVIEW.
