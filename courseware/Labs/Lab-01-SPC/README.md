# SPC — 25-minute guided Excel exercise

Module 3 only. Use the prepared Worked-Reference.xlsx; all three exercises use one working copy.

## 5 min · Read the prepared analysis

Open Worked-Reference.xlsx and save a working copy. The trainer has prepared data cleaning, unit conversion, baseline formulas and chart. Locate RawTests, Analysis and SPC_Summary; keep the source and baseline limits unchanged.

## 12 min · Prompt and inspect

Use SPC3 from Prompts to explain the existing chart and identify outside-limit points. If editing is available, add a signal flag in a copy. Check TEST-073 and one baseline row against fixed limits 60.03757–63.96743 L/h. Do not rebuild the chart or calculate Cp/Cpk in class.

## 8 min · Verify and retain

Confirm 17 valid monitoring points outside the limits. Save one three-sentence interpretation: signal, evidence and limitation. An association does not establish the cause. Stop at the time limit.

## Optional after class — not scheduled

Starter.xlsx and the complete prompts.md bank support rebuilding the analysis, chart and extended review later. Only the selected core prompt is required in class.
