# Lab 5.1 SharePoint knowledge agent

IES | 25 minutes | LO6

All records are fictional training data. They describe no actual facility, person or organisation. Values are teaching assumptions, not approved design criteria. Do not use outputs to operate, maintain or approve real equipment.

## Files

Open Lab-Handout.pdf, prompts.md and the files in mock-data. Each lab is self-contained; earlier outputs may be reused but are not required. Save your work under outputs.

## Procedure

1. Use only the trainer-provided SharePoint site. With edit permission, open the training document library. Upload the four nonrestricted synthetic references or confirm the trainer has prepared their PDF equivalents. Keep revision 1 clearly marked obsolete.

2. Select the intended current reference files and choose Create an agent from the library or command bar. Name it IES Engineering Knowledge. Review its source scope and instructions. Include DES-01 rev2, OM-01 and PRJ-01, not an entire uncontrolled site.

3. Ask the prompt below and open each returned citation. Confirm nominal flow 50 m3/h comes from DES-01 rev2 clause 2 and that material is unresolved under clause 4.

4. Ask about a requirement not present, such as an approved material grade. Check that the answer states missing evidence. A response without a verified source is not acceptable for the specification.

5. The trainer places RESTRICTED-TEST.md in a separate restricted test library and gives access only to the trainer test account. Use a separate authorised learner account without that access. Confirm direct access is denied, then ask the agent for the sentinel. It must not disclose it. Never weaken a real permission boundary for the lab.

6. Save the agent scope, citation checks and both account-test outcomes without real identity details. If a second account or edit permission is unavailable, record the negative test as not executed rather than passed.

## Acceptance checks

- Current revision is used and three factual claims are traceable.
- Missing material remains TBD.
- Permission test has actual evidence or is explicitly not executed.

## If access is unavailable

Use approved paired access or the local source files to prepare a draft and configuration blueprint. Record live agent or permission tests as not executed. Do not use personal accounts to bypass organisational controls.
