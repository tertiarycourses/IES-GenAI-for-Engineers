# Weekly Engineering Report Template

Fictional training reference. Follow this structure exactly.

1. **Reporting period** - the dates covered, as stated in the source.
2. **Completed this period** - only work evidenced as done. A plan is not completion.
3. **In progress** - with the action ID and owner.
4. **Open blockers** - what is stopping work, and who is waiting on whom.
5. **Actions table** - Action ID, description, owner, due date, status, evidence reference.
6. **Unresolved assumptions** - everything the report depends on but cannot show.
7. **Reviewer decision** - left blank for a human.

## Rules

- Preserve every action ID, owner, due date and evidence reference exactly as supplied.
- Where the source does not state an owner or a date, write NOT STATED. Never assign one.
- Never invent budget figures, completion percentages, certificates or approvals.
- Cite the source document and version for each factual claim.
- Final status is always draft.
