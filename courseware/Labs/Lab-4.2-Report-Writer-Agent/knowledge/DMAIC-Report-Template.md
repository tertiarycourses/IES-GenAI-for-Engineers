# DMAIC Summary Template

Fictional training reference. Return exactly five rows.

| Phase | What belongs here |
|---|---|
| Define | The problem as stated in the source, and the boundary of what was examined. |
| Measure | The measured figures with their formulas, units and row counts. |
| Analyse | What the numbers show. Hypotheses are labelled as hypotheses. |
| Improve | The change that was made or proposed, and by whom. |
| Control | How the change would be held, and what evidence is still missing. |

## Rules

- Show the formula for every rate, for example deviations divided by opportunities.
- Separate observed facts from hypotheses in every row.
- A short pilot does not prove the cause of a change. State this explicitly.
- Concurrent changes make attribution unsafe. Name them when present.
- Close with one next evidence check.
