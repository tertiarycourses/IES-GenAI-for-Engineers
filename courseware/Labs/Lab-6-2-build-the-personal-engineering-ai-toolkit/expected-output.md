# Expected output example

Illustrative teaching example, not a recorded Copilot run or an approved engineering result.

Next action: trial inspection-note summarisation on fictional records next week; compare total drafting plus review time and unsupported claims. Stop if a source cannot be traced or the tenant access is unapproved.

## Acceptance checks

- Two prompt frameworks and one testable next action are present.
- Live agent status is honest and a human review gate remains.

## Worked one week trial plan

Workflow: draft a structured inspection report from approved fictional notes. Owner: learner. Due: choose a specific date next week. Inputs: named source and version. Prompt: tested R.I.S.E. specification with a verification request. Review: trace each value and uncertainty to the source. Measure: draft, review and correction minutes plus unsupported-claim count. Stop: missing authority, unapproved access or untraceable evidence. Next decision: continue, revise or abandon after the measured trial.
