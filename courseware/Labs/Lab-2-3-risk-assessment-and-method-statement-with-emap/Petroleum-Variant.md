# Petroleum risk and method outline

Petroleum transfer pathway: choose this scenario instead of the original lab within the same time allocation. Additional explanations are reference reading. All petroleum records, limits, outputs and scores here are original fictional teaching examples; no operating action is authorised.

1. Open petroleum-data in this lab folder. Read PET-DES rev2 and PET-INS; inspect the CSV headers and retain the raw files.

2. Use E-MAP to create a desk-review risk register for the fictional skid. Consider pressure, electrical energy, unknown fluid and access. State missing approved procedures and release hold points.

3. Follow the original lab tool-setup steps, substituting these petroleum filenames. Run petroleum-prompts.md using approved tools. Save the initial response and identify each unsupported statement.

4. Independently check the cited clauses, units and numerical results against the supplied records. Record corrections in a cleaning or review ledger.

5. Save the revised output, prompt log, independent checks and reviewer status. Mark any unavailable tool or unexecuted test explicitly.
