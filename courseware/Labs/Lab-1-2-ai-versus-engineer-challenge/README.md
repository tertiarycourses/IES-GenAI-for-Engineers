# Lab 1.2 AI versus engineer challenge

IES | 15 minutes | LO2, LO3

All records are fictional training data. They describe no actual facility, person or organisation. Values are teaching assumptions, not approved design criteria. Do not use outputs to operate, maintain or approve real equipment.

## Files

Open Lab-Handout.pdf, prompts.md and the files in mock-data. Each lab is self-contained; earlier outputs may be reused but are not required. Save your work under outputs.

## Procedure

1. Open problem-statement.txt. In pairs, assign one learner to write manually and the other to use Copilot Chat. Start the same five-minute timer and use the same source.

2. Prepare a technical brief with context, observations, unknowns, hypotheses, evidence requests and decision owner. The AI participant uses the prompt below; the manual participant uses the same headings.

3. Compare each factual statement with the source. Mark unsupported assertions in claim-register.csv. In particular, distinguish a reported vibration from a measured vibration value.

4. Ask Copilot to repair unsupported claims. Record original draft time, review time and revision time separately. Do not compare draft speed alone.

5. Save the corrected brief and a three-sentence comparison. Identify one decision that remains with an engineer and one repeatable drafting task suited to AI.

## Acceptance checks

- Facts match the notes and unknowns stay unknown.
- Timing includes human review and the brief has a decision owner.

## If access is unavailable

Use approved paired access or the local source files to prepare a draft and configuration blueprint. Record live agent or permission tests as not executed. Do not use personal accounts to bypass organisational controls.
