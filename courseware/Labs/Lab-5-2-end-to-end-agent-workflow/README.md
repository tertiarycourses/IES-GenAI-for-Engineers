# Lab 5.2 End to end agent workflow

IES | 15 minutes | LO6

All records are fictional training data. They describe no actual facility, person or organisation. Values are teaching assumptions, not approved design criteria. Do not use outputs to operate, maintain or approve real equipment.

## Files

Open Lab-Handout.pdf, prompts.md and the files in mock-data. Each lab is self-contained; earlier outputs may be reused but are not required. Save your work under outputs.

## Procedure

1. Query the SharePoint knowledge agent for current duty requirements and unresolved material status. If no live agent is available, retrieve the clauses manually from local inputs and label that route.

2. Complete handoff-template.md with source title, revision, clause, supported statement and uncertainty. Open the source to verify every statement before passing it forward.

3. Pass the reviewed handoff to IES FMEA Assistant or IES Report Writer. The standalone files in this lab support a prompt-based fallback if earlier agents are unavailable.

4. Generate one engineering document with traceable source references. Check that the downstream agent has not removed TBD material or converted a planning note into approval.

5. Save the retrieved evidence, handoff and final draft. Ask a peer to trace one sentence backwards through both stages to the original clause. Mark the reviewer decision separately.

## Acceptance checks

- Each claim can be traced through the handoff to the source.
- No uncertainty or permissions are lost during transfer.

## If access is unavailable

Use approved paired access or the local source files to prepare a draft and configuration blueprint. Record live agent or permission tests as not executed. Do not use personal accounts to bypass organisational controls.
