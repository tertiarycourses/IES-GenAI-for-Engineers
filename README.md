# IES GenAI for Engineers

![Course preview](screenshot.png)

A one-day, six-module courseware package aligned to **GenAI for Engineers — Lesson Plan with Hands-On Labs (v2 — PUB Feedback)**. The 194-slide deck contains 169 teaching and closing slides plus 25 optional quick-reference pages. Facilitators select the relevant worked slides within each fixed module time box.

- [PowerPoint — 194 slides](courseware/Slides/IES-GenAI-for-Engineers.pptx)
- [Slide PDF — 194 pages](courseware/Slides/IES-GenAI-for-Engineers.pdf)
- [Learner Guide](courseware/Learner-Guide/IES-GenAI-for-Engineers-Learner-Guide.pdf)
- [Lesson Plan](courseware/Lesson-Plan/IES-GenAI-for-Engineers-Lesson-Plan.pdf)
- [Sixteen aligned activity folders](courseware/Labs/README.md)
- [Alignment matrix](courseware/ALIGNMENT-MATRIX.md)

The deck explains FMEA, DMAIC and SPC before application, in that classroom-case order. It also teaches prompt engineering through R.I.S.E., E-MAP, constraints, iterative review, multiple personas and structured debate. Microsoft 365 Copilot, Copilot Agents, Researcher, Analyst, SharePoint grounding and the 7-Step AI Security Framework are connected to the same synthetic CW-401 engineering case.

Every activity folder uses one detailed `README.md` as the editable source and one matching `Lab-Instructions.pdf` as the learner copy. The complete prompt, procedure, independent checks and acceptance conditions are embedded in both, avoiding conflicting prompt and handout files. Labs 3.1, 3.2 and 3.3 include editable Excel workbooks. All provider branding is IES.
